## 打开方式

在本目录运行：

```bash
npm start
```

然后访问 `http://localhost:4173`。

### HarmonyOS 7 独立适配预览

访问 `http://localhost:4173/os7.html`，可体验CSS背景模糊、滚动联动顶栏、自定义频道切换和弹层拖拽、按压反馈、浏览器深浅色和减少动态效果。网页背景的高透明/标准/低透明/实体为项目自定义设置，未接入鸿蒙系统材质档位、设备算力或握姿识别。视觉方向仍待用户评审。

弹簧运动模型的回归测试：`node tests/os7-motion.test.cjs`。本次修改及验证边界见 [自然交互修订](OS7_ADAPTATION.md#2026-09-20-自然交互修订)。

## 已实现的交互

以下为原版复刻行为；OS7 入口的差异以适配说明为准。

- 顶部频道支持点击或左右跟手滑动，松手后按距离和速度吸附到目标频道。
- 一级频道通过字号、字重与颜色区分选中态；蓝色下划线仅用于车型筛选栏。
- 首次频道加载显示参考视频中的圆环与“正在加载…”状态。
- 每个频道拥有独立纵向滚动位置；顶部标题栏和底部一级导航保持固定。
- 发现页车型栏吸顶，支持下拉、松开刷新、刷新中与刷新完成状态。
- 精选页头部叠在首屏宣传图上，滚动后过渡为白底深色文字。
- 底部「发现 / 精选 / 爱车 / 服务 / 我的」直接切换一级页面并保留浏览状态。
- 爱车页复刻车辆资源未就绪、下载弹层、下载进度、资源加载完成和车辆 Hero 恢复等状态。
- 爱车页上滑后告警收拢进标题栏。离线车控点击显示“车辆不在线”，不会伪装真实车控成功。
- 服务、我的页面均为真实长页面，可连续滚动并触发组件状态。
- 键盘方向键支持频道切换和页面滚动，`Esc` 可关闭弹层。

## 页面参数

地址栏支持直接指定一级页面与频道，例如：

```text
?page=discover&channel=1
?page=select&channel=3
?page=car
```

当前加载 `reference.js` 与 `reference.css`。前一版 `app.js`、`styles.css` 保留作为历史文件，入口不再加载。源图素材、裁切坐标与验证说明见 `REFERENCE_ACCEPTANCE.md`。
